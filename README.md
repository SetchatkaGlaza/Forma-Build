# FORMA BUILD

Концептуальный корпоративный сайт строительной компании, специализирующейся на проектировании и строительстве частных домов. Проект демонстрирует структуру презентационного сайта, визуальную подачу архитектурных проектов и интерактивные элементы для работы с потенциальными клиентами.

## Возможности

- Адаптивная верстка для мобильных устройств, планшетов и настольных экранов.
- Каталог проектов с фильтрацией и просмотром изображений в галерее.
- Разделы услуг, этапов работы, материалов и технических решений.
- Калькулятор предварительной оценки стоимости строительства.
- Форма обратной связи с проверкой введенных данных.
- Навигация с учетом текущего раздела страницы.
- Плавные анимации и интерактивные состояния элементов.
- Поддержка настройки уменьшенного движения через `prefers-reduced-motion`.
- Оптимизированные изображения для разных размеров экрана.
- Страница 404, метаданные для социальных сетей, favicon, `robots.txt` и `sitemap.xml`.

## Технологии

- **HTML5** — семантическая структура страниц.
- **CSS3** — стилизация, адаптивная сетка и анимации.
- **JavaScript (ES Modules)** — интерактивность и логика компонентов.
- **Vite** — локальный сервер разработки и production-сборка.
- **GitHub Actions / GitHub Pages** — автоматическая сборка и публикация.

Проект реализован без JavaScript-фреймворков.

## Запуск проекта

### Требования

- Node.js 18 или новее.
- npm.

### Установка

```bash
git clone https://github.com/<username>/<repository>.git
cd forma-build
npm install
```

### Режим разработки

```bash
npm run dev
```

Vite выведет локальный адрес сайта в терминале — обычно `http://localhost:5173`.

### Production-сборка

```bash
npm run build
```

Готовые файлы будут помещены в каталог `dist/`.

Чтобы проверить production-сборку локально:

```bash
npm run preview
```

## Публикация на GitHub Pages

В репозитории настроен workflow GitHub Actions для сборки и публикации сайта при обновлении ветки `main`.

1. Откройте **Settings → Pages** в настройках репозитория.
2. В разделе **Build and deployment** выберите источник **GitHub Actions**.
3. Отправьте изменения в ветку `main` или запустите workflow вручную во вкладке **Actions**.

После завершения workflow адрес опубликованного сайта появится в настройках Pages и в результате развертывания.

Перед публикацией на собственном домене проверьте адреса в `public/robots.txt` и `public/sitemap.xml`, а также метаданные сайта в `index.html`.

## Примечания

- FORMA BUILD — концептуальный проект для портфолио. Название компании, проекты, цены и контактные данные представлены в демонстрационных целях.
- Калькулятор показывает ориентировочную оценку и не заменяет коммерческую смету.
- Форма обратной связи работает в демонстрационном режиме, если не настроен внешний endpoint. Для приема заявок задайте `VITE_FORM_ENDPOINT` в окружении сборки согласно логике `src/scripts/form.js`.
- Перед использованием сайта в коммерческих целях замените демонстрационные сведения, проверьте юридические тексты и подключите обработку заявок.
